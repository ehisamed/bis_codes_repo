# Вариант 10 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\sqrt{b+\cos^2 a + e^{c}}}{|a+b+c|}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = sqrt(b + pow(cos(a), 2) + exp(c)) / fabs(a + b + c);

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `sqrt`, `cos`, `pow`, `exp`, `fabs`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = sqrt(b + pow(cos(a), 2) + exp(c)) / fabs(a + b + c);` — вычисление:
   - `cos(a)` — косинус $a$; `pow(cos(a), 2)` — это $\cos^2 a$;
   - `exp(c)` — вычисляет $e^{c}$;
   - `b + pow(cos(a), 2) + exp(c)` — сумма под корнем $b+\cos^2 a+e^{c}$;
   - `sqrt(...)` — квадратный корень этой суммы — числитель;
   - `a + b + c` — сумма всех переменных; `fabs(...)` — модуль этой суммы — знаменатель $|a+b+c|$;
   - результат деления присваивается `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=0  b=1  c=0`
Расчёт: `cos(0)=1`, `cos^2(0)=1`; `e^0=1`; сумма под корнем `=1+1+1=3`, `sqrt(3)≈1.732051`; `|0+1+0|=1`.
Вывод: `y ≈ 1.732051`
