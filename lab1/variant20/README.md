# Вариант 20 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\ln a^{b} + 10^{b+c}}{a\sqrt{c^2+1}}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (log(pow(a, b)) + pow(10, b + c)) / (a * sqrt(pow(c, 2) + 1));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `log`, `pow`, `sqrt`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (log(pow(a, b)) + pow(10, b + c)) / (a * sqrt(pow(c, 2) + 1));` — вычисление:
   - `pow(a, b)` — это $a^{b}$; `log(...)` — натуральный логарифм $\ln a^{b}$;
   - `pow(10, b + c)` — это $10^{b+c}$; сумма даёт числитель;
   - `pow(c, 2)` — это $c^2$; `pow(c,2) + 1` — прибавляем 1; `sqrt(...)` — квадратный корень $\sqrt{c^2+1}$;
   - `a * sqrt(...)` — знаменатель $a\sqrt{c^2+1}$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=2  b=1  c=0`
Расчёт: `a^b=2`, `ln(2)≈0.693147`; `10^(1+0)=10`; числитель `≈10.693147`. `a*sqrt(0+1)=2*1=2`.
Вывод: `y ≈ 5.346574`
