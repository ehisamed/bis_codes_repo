# Вариант 3 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{2\cos^2(c^3) + 3a}{a(|b\cos a|+1)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (2 * pow(cos(pow(c, 3)), 2) + 3 * a) / (a * (fabs(b * cos(a)) + 1));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — подключает ввод/вывод.
2. `#include <cmath>` — подключает `pow`, `cos`, `fabs`.
3. `using namespace std;` — не нужно писать `std::`.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — объявляем переменные для данных (`a`,`b`,`c`) и результата (`y`).
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение трёх чисел.
8. `y = (2 * pow(cos(pow(c, 3)), 2) + 3 * a) / (a * (fabs(b * cos(a)) + 1));` — вычисление:
   - `pow(c, 3)` — это $c^3$;
   - `cos(pow(c, 3))` — косинус от $c^3$;
   - `pow(cos(pow(c, 3)), 2)` — квадрат этого косинуса, то есть $\cos^2(c^3)$;
   - `2 * ... + 3 * a` — числитель $2\cos^2(c^3) + 3a$;
   - `cos(a)` — косинус $a$; `b * cos(a)` — произведение $b\cos a$; `fabs(...)` — модуль $|b\cos a|$;
   - `a * (fabs(b * cos(a)) + 1)` — знаменатель $a(|b\cos a|+1)$;
   - деление числителя на знаменатель даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=1  c=0`
Расчёт: `c^3=0`, `cos(0)=1`, `cos^2(0)=1`, `2*1+3*1=5`; `cos(1)≈0.540302`, `|1*cos(1)|+1≈1.540302`.
Вывод: `y ≈ 3.246117`
