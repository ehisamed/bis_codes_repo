# Вариант 5 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\sqrt{|a|^{b} - 2}}{b(c^3-1)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = sqrt(pow(fabs(a), b) - 2) / (b * (pow(c, 3) - 1));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `sqrt` (корень), `pow` (степень), `fabs` (модуль).
3. `using namespace std;` — сокращает запись стандартных имён.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — объявление переменных.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел `a`, `b`, `c`.
8. `y = sqrt(pow(fabs(a), b) - 2) / (b * (pow(c, 3) - 1));` — вычисление:
   - `fabs(a)` — модуль $|a|$;
   - `pow(fabs(a), b)` — возводит $|a|$ в степень $b$, то есть $|a|^b$;
   - `pow(fabs(a), b) - 2` — вычитаем 2;
   - `sqrt(...)` — извлекаем квадратный корень — числитель $\sqrt{|a|^b - 2}$;
   - `pow(c, 3)` — это $c^3$; `pow(c, 3) - 1` — вычитаем 1;
   - `b * (...)` — знаменатель $b(c^3-1)$;
   - деление числителя на знаменатель даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение программы.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=2  b=2  c=2`
Расчёт: `|a|^b=4`, `4-2=2`, `sqrt(2)≈1.414214`; `c^3-1=7`, `b*7=14`.
Вывод: `y ≈ 0.101015`
