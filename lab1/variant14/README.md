# Вариант 14 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\sin 10^{a} + \sqrt{b^2+c^2}}{a\,\mathrm{tg}\dfrac{b}{c}}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (sin(pow(10, a)) + sqrt(pow(b, 2) + pow(c, 2))) / (a * tan(b / c));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `sin`, `pow`, `sqrt`, `tan`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (sin(pow(10, a)) + sqrt(pow(b, 2) + pow(c, 2))) / (a * tan(b / c));` — вычисление:
   - `pow(10, a)` — это $10^{a}$; `sin(...)` — синус этого значения $\sin 10^{a}$;
   - `pow(b,2)` и `pow(c,2)` — квадраты $b^2$ и $c^2$; их сумма под корнем;
   - `sqrt(...)` — квадратный корень $\sqrt{b^2+c^2}$;
   - сумма даёт числитель;
   - `b / c` — деление; `tan(...)` — тангенс отношения $\mathrm{tg}(b/c)$;
   - `a * tan(b / c)` — знаменатель;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=1  c=1`
Расчёт: `10^1=10`, `sin(10)≈-0.544021` (аргумент в радианах); `sqrt(1^2+1^2)=sqrt(2)≈1.414214`; числитель `≈0.870192`. `b/c=1`, `tan(1)≈1.557408`; знаменатель `=1*1.557408≈1.557408`.
Вывод: `y ≈ 0.558745`
