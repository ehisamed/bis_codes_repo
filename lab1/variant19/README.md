# Вариант 19 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\ln|a| + b^{c}}{c(10^{a} - b^2)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (log(fabs(a)) + pow(b, c)) / (c * (pow(10, a) - pow(b, 2)));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `log`, `fabs`, `pow`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (log(fabs(a)) + pow(b, c)) / (c * (pow(10, a) - pow(b, 2)));` — вычисление:
   - `fabs(a)` — модуль $|a|$; `log(...)` — натуральный логарифм $\ln|a|$;
   - `pow(b, c)` — это $b^{c}$; сумма даёт числитель;
   - `pow(10, a)` — это $10^{a}$; `pow(b, 2)` — это $b^2$; разность в скобках;
   - `c * (...)` — знаменатель $c(10^a - b^2)$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=2  c=1`
Расчёт: `ln|1|=0`, `b^c=2`; числитель `=2`; `10^a=10`, `b^2=4`, `c*(10-4)=6`.
Вывод: `y ≈ 0.333333`
