# Вариант 4 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{a|b+c| + \ln b^2}{a\,\lg^2(c+1)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (a * fabs(b + c) + log(pow(b, 2))) / (a * pow(log10(c + 1), 2));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `fabs`, `log` (натуральный логарифм), `pow`, `log10` (десятичный логарифм).
3. `using namespace std;` — упрощает написание `cout`/`cin`.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — считывание трёх чисел.
8. `y = (a * fabs(b + c) + log(pow(b, 2))) / (a * pow(log10(c + 1), 2));` — вычисление:
   - `fabs(b + c)` — модуль суммы, то есть $|b+c|$;
   - `a * fabs(b + c)` — произведение $a|b+c|$;
   - `pow(b, 2)` — это $b^2$; `log(...)` — натуральный логарифм $\ln b^2$;
   - сумма даёт числитель $a|b+c| + \ln b^2$;
   - `log10(c + 1)` — десятичный логарифм $\lg(c+1)$; `pow(..., 2)` — возводит его в квадрат $\lg^2(c+1)$;
   - `a * pow(log10(c + 1), 2)` — знаменатель $a\lg^2(c+1)$;
   - итог деления записывается в `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — программа завершена без ошибок.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=2  c=1`
Расчёт: `|b+c|=3`, числитель `= 1*3 + ln(4) = 3+1.386294 = 4.386294`; знаменатель `= 1*lg^2(2) = 0.090619`.
Вывод: `y ≈ 48.4037`
