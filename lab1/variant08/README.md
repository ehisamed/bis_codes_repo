# Вариант 8 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\sqrt{2^{a+b}} + \arccos c}{b\,\mathrm{arctg}\dfrac{b}{c}}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (sqrt(pow(2, a + b)) + acos(c)) / (b * atan(b / c));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `sqrt` (корень), `pow` (степень), `acos` (арккосинус), `atan` (арктангенс).
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (sqrt(pow(2, a + b)) + acos(c)) / (b * atan(b / c));` — вычисление:
   - `pow(2, a + b)` — это $2^{a+b}$; `sqrt(...)` — квадратный корень из него;
   - `acos(c)` — арккосинус $c$ (результат в радианах, `c` должно быть в диапазоне $[-1,1]$);
   - сумма даёт числитель $\sqrt{2^{a+b}} + \arccos c$;
   - `b / c` — деление $b$ на $c$; `atan(...)` — арктангенс этого отношения;
   - `b * atan(b / c)` — знаменатель $b\,\mathrm{arctg}(b/c)$;
   - результат деления присваивается `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=1  c=0.5`
Расчёт: `2^(a+b)=4`, `sqrt(4)=2`; `arccos(0.5)≈1.047198` (это π/3); числитель `≈3.047198`. `b/c=2`, `arctg(2)≈1.107149`; знаменатель `≈1.107149`.
Вывод: `y ≈ 2.752293`
