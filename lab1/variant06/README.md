# Вариант 6 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{a - 2\sin^3 b}{a(\mathrm{tg}\,c + b)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (a - 2 * pow(sin(b), 3)) / (a * (tan(c) + b));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `sin`, `pow`, `tan`.
3. `using namespace std;` — упрощение записи.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (a - 2 * pow(sin(b), 3)) / (a * (tan(c) + b));` — вычисление:
   - `sin(b)` — синус $b$ (в радианах);
   - `pow(sin(b), 3)` — куб синуса, то есть $\sin^3 b$;
   - `a - 2 * ...` — числитель $a - 2\sin^3 b$;
   - `tan(c)` — тангенс $c$; `tan(c) + b` — сумма $\mathrm{tg}\,c + b$;
   - `a * (...)` — знаменатель $a(\mathrm{tg}\,c+b)$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=1  c=0`
Расчёт: `sin(1)≈0.841471`, `sin^3(1)≈0.595823`; числитель `= 1 - 2*0.595823 = -0.191647`; знаменатель `= 1*(tan(0)+1) = 1`.
Вывод: `y ≈ -0.191647`
