# Вариант 12 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\ln(a^2+b^2) + \lg c}{b(a^{b}+c)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (log(pow(a, 2) + pow(b, 2)) + log10(c)) / (b * (pow(a, b) + c));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `log` (натуральный логарифм), `pow`, `log10` (десятичный логарифм).
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (log(pow(a, 2) + pow(b, 2)) + log10(c)) / (b * (pow(a, b) + c));` — вычисление:
   - `pow(a,2)` и `pow(b,2)` — квадраты $a^2$ и $b^2$; их сумма — аргумент логарифма;
   - `log(...)` — натуральный логарифм $\ln(a^2+b^2)$;
   - `log10(c)` — десятичный логарифм $\lg c$;
   - сумма даёт числитель $\ln(a^2+b^2)+\lg c$;
   - `pow(a, b)` — это $a^{b}$; `pow(a,b) + c` — прибавляем $c$;
   - `b * (...)` — знаменатель $b(a^b+c)$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=1  c=1`
Расчёт: `ln(1^2+1^2)=ln(2)≈0.693147`, `lg(1)=0`; числитель `≈0.693147`. `a^b=1`, `+c=2`, `b*2=2`.
Вывод: `y ≈ 0.346574`
