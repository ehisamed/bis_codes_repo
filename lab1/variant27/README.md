# Вариант 27 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\ln(a^2+b^2) + b^{c}}{abc}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (log(pow(a, 2) + pow(b, 2)) + pow(b, c)) / (a * b * c);

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `log`, `pow`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (log(pow(a, 2) + pow(b, 2)) + pow(b, c)) / (a * b * c);` — вычисление:
   - `pow(a,2)` и `pow(b,2)` — квадраты $a^2$, $b^2$; сумма — аргумент логарифма;
   - `log(...)` — натуральный логарифм $\ln(a^2+b^2)$;
   - `pow(b, c)` — это $b^{c}$; сумма даёт числитель;
   - `a * b * c` — произведение всех переменных — знаменатель $abc$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=2  c=1`
Расчёт: `a^2+b^2=5`, `ln(5)≈1.609438`; `b^c=2`; числитель `≈3.609438`; `a*b*c=2`.
Вывод: `y ≈ 1.804719`
