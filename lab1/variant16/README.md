# Вариант 16 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\arccos^2 b - e^{a+b}}{|a|(b+c)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (pow(acos(b), 2) - exp(a + b)) / (fabs(a) * (b + c));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `pow`, `acos`, `exp`, `fabs`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (pow(acos(b), 2) - exp(a + b)) / (fabs(a) * (b + c));` — вычисление:
   - `acos(b)` — арккосинус $b$ (нужно $b\in[-1,1]$); `pow(acos(b), 2)` — квадрат $\arccos^2 b$;
   - `exp(a + b)` — вычисляет $e^{a+b}$;
   - разность даёт числитель $\arccos^2 b - e^{a+b}$;
   - `fabs(a)` — модуль $|a|$; `b + c` — сумма $b+c$;
   - произведение даёт знаменатель $|a|(b+c)$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=0  c=1`
Расчёт: `arccos(0)≈1.570796`, в квадрате `≈2.467401`; `e^(1+0)=e≈2.718282`; числитель `≈-0.250881`. `|a|=1`, `b+c=1`.
Вывод: `y ≈ -0.250881`
