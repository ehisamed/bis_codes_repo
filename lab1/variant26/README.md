# Вариант 26 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{e^{c} + |b^2-a|}{a\ln^2(b+c)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (exp(c) + fabs(pow(b, 2) - a)) / (a * pow(log(b + c), 2));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `exp`, `fabs`, `pow`, `log`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (exp(c) + fabs(pow(b, 2) - a)) / (a * pow(log(b + c), 2));` — вычисление:
   - `exp(c)` — вычисляет $e^{c}$;
   - `pow(b, 2)` — это $b^2$; `pow(b,2) - a` — разность; `fabs(...)` — модуль $|b^2-a|$;
   - сумма даёт числитель;
   - `log(b + c)` — натуральный логарифм $\ln(b+c)$ (нужно $b+c>0$); `pow(..., 2)` — возводит в квадрат $\ln^2(b+c)$;
   - `a * pow(...)` — знаменатель;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=1  c=1`
Расчёт: `e^1≈2.718282`; `b^2-a=0`, `|0|=0`; числитель `≈2.718282`. `b+c=2`, `ln(2)≈0.693147`, в квадрате `≈0.480453`; `a*0.480453≈0.480453`.
Вывод: `y ≈ 5.657749`
