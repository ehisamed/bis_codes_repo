# Вариант 7 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{e^{a} + |b|}{a\ln(c^4+1)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (exp(a) + fabs(b)) / (a * log(pow(c, 4) + 1));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `exp` (экспонента), `fabs` (модуль), `log` (натуральный логарифм), `pow` (степень).
3. `using namespace std;` — упрощает написание кода.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — объявление переменных.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (exp(a) + fabs(b)) / (a * log(pow(c, 4) + 1));` — вычисление:
   - `exp(a)` — вычисляет $e^{a}$;
   - `fabs(b)` — модуль $|b|$;
   - сумма даёт числитель $e^{a} + |b|$;
   - `pow(c, 4)` — это $c^4$; `log(pow(c,4)+1)` — натуральный логарифм $\ln(c^4+1)$;
   - `a * log(...)` — знаменатель $a\ln(c^4+1)$;
   - результат деления присваивается `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=1  c=1`
Расчёт: `e^1≈2.718282`, `+|b|=1` → числитель `≈3.718282`; `c^4+1=2`, `ln(2)≈0.693147`, `a*0.693147≈0.693147`.
Вывод: `y ≈ 5.364346`
