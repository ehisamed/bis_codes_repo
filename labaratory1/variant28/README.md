# Вариант 28 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\lg a^{3} + b^{a+c}}{(a+b)10^{c}}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (log10(pow(a, 3)) + pow(b, a + c)) / ((a + b) * pow(10, c));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `log10`, `pow`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (log10(pow(a, 3)) + pow(b, a + c)) / ((a + b) * pow(10, c));` — вычисление:
   - `pow(a, 3)` — это $a^3$; `log10(...)` — десятичный логарифм $\lg a^{3}$ (нужно $a>0$);
   - `pow(b, a + c)` — это $b^{a+c}$; сумма даёт числитель;
   - `pow(10, c)` — это $10^{c}$; `(a + b) * pow(10, c)` — знаменатель $(a+b)10^{c}$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=2  c=0`
Расчёт: `a^3=1`, `lg(1)=0`; `b^(a+c)=2^1=2`; числитель `=0+2=2`. `(a+b)=3`, `10^0=1`; знаменатель `=3`.
Вывод: `y ≈ 0.666667`
