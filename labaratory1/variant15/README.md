# Вариант 15 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\arccos^2 a - b^2}{b(c-1)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (pow(acos(a), 2) - pow(b, 2)) / (b * (c - 1));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `pow`, `acos` (арккосинус).
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (pow(acos(a), 2) - pow(b, 2)) / (b * (c - 1));` — вычисление:
   - `acos(a)` — арккосинус $a$; `pow(acos(a), 2)` — квадрат арккосинуса $\arccos^2 a$;
   - `pow(b, 2)` — это $b^2$; разность даёт числитель $\arccos^2 a - b^2$;
   - `c - 1` — вычитаем единицу; `b * (c - 1)` — знаменатель $b(c-1)$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=0  b=1  c=0`
Расчёт: `arccos(0)≈1.570796`, в квадрате `≈2.467401`; `b^2=1`, числитель `≈1.467401`; `c-1=-1`, `b*(-1)=-1`.
Вывод: `y ≈ -1.467401`
