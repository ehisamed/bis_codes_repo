# Вариант 24 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{b^2\arcsin c}{c(\cos a^3+1)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (pow(b, 2) * asin(c)) / (c * (cos(pow(a, 3)) + 1));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `pow`, `asin` (арксинус), `cos`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (pow(b, 2) * asin(c)) / (c * (cos(pow(a, 3)) + 1));` — вычисление:
   - `pow(b, 2)` — это $b^2$; `asin(c)` — арксинус $\arcsin c$ (нужно $c\in[-1,1]$);
   - произведение даёт числитель $b^2\arcsin c$;
   - `pow(a, 3)` — это $a^3$; `cos(...)` — косинус $\cos a^3$; прибавляем 1;
   - `c * (...)` — знаменатель $c(\cos a^3+1)$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=0  b=1  c=0.5`
Расчёт: `arcsin(0.5)≈0.523599` (π/6); `b^2=1`; числитель `≈0.523599`. `a^3=0`, `cos(0)=1`, `+1=2`; `c*2=1`.
Вывод: `y ≈ 0.523599`
