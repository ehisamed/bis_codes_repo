# Вариант 25 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\sqrt{\arcsin^2 b + 1}}{c(e^{a}+|b|)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = sqrt(pow(asin(b), 2) + 1) / (c * (exp(a) + fabs(b)));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `sqrt`, `pow`, `asin`, `exp`, `fabs`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = sqrt(pow(asin(b), 2) + 1) / (c * (exp(a) + fabs(b)));` — вычисление:
   - `asin(b)` — арксинус $b$; `pow(asin(b), 2)` — квадрат $\arcsin^2 b$; прибавляем 1;
   - `sqrt(...)` — квадратный корень — числитель;
   - `exp(a)` — вычисляет $e^{a}$; `fabs(b)` — модуль $|b|$; сумма в скобках;
   - `c * (...)` — знаменатель $c(e^a+|b|)$;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=0  b=0.5  c=1`
Расчёт: `arcsin(0.5)≈0.523599`, в квадрате `≈0.274156`, `+1≈1.274156`, `sqrt(...)≈1.128785`; `e^0=1`, `|b|=0.5`, `c*1.5=1.5`.
Вывод: `y ≈ 0.752524`
