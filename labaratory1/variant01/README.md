# Вариант 1 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{2a - 3\ln(b^2+1)}{b(1+\cos^2 c)}$$

## Блок-схема
Файл `scheme.drawio` — открыть на https://app.diagrams.net или расширением Draw.io в VS Code.
Схема: Начало → Ввод a, b, c → Вычисление y → Вывод y → Конец.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (2 * a - 3 * log(pow(b, 2) + 1)) / (b * (1 + pow(cos(c), 2)));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно (для новичка)

1. `#include <iostream>` — подключает библиотеку для ввода/вывода. Без неё не будут работать `cin` и `cout`.
2. `#include <cmath>` — подключает библиотеку математических функций: `log` (натуральный логарифм), `pow` (возведение в степень), `cos` (косинус) и др.
3. `using namespace std;` — разрешает писать `cout`, `cin`, `endl` без приставки `std::`.
4. `int main() {` — точка входа в программу. Всё, что внутри фигурных скобок, выполняется при запуске.
5. `double a, b, c, y;` — объявляем 4 переменные вещественного типа (могут хранить дробные числа): `a`, `b`, `c` — исходные данные, `y` — результат.
6. `cout << "Vvedite a, b, c: ";` — печатает на экране подсказку, что нужно ввести три числа.
7. `cin >> a >> b >> c;` — считывает с клавиатуры три числа по очереди и кладёт их в `a`, `b`, `c`.
8. `y = (2 * a - 3 * log(pow(b, 2) + 1)) / (b * (1 + pow(cos(c), 2)));` — вычисляем формулу:
   - `pow(b, 2)` — это $b^2$;
   - `log(pow(b, 2) + 1)` — это $\ln(b^2+1)$ (в C++ `log` — натуральный логарифм);
   - `2 * a - 3 * log(...)` — числитель $2a - 3\ln(b^2+1)$;
   - `cos(c)` — косинус c (в радианах);
   - `pow(cos(c), 2)` — это $\cos^2 c$;
   - `b * (1 + pow(cos(c), 2))` — знаменатель $b(1+\cos^2 c)$;
   - результат деления числителя на знаменатель записывается в `y`.
9. `cout << "y = " << y << endl;` — выводит результат на экран; `endl` переводит строку.
10. `return 0;` — сообщает системе, что программа завершилась успешно (без ошибок).
11. `}` — закрывающая скобка функции `main`.

## Пример работы (тест)
Ввод: `a=1  b=2  c=0`
Расчёт: `b^2+1=5`, `ln(5)≈1.609438`, `3*ln(5)≈4.828314`; числитель `=2*1-4.828314≈-2.828314`. `cos(0)=1`, `1+cos^2(0)=2`, `b*2=4`.
Вывод: `y ≈ -0.707078`
