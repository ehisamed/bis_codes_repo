# Вариант 2 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\mathrm{tg}(a^3 - |b|)}{c\,e^{b}}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = tan(pow(a, 3) - fabs(b)) / (c * exp(b));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — подключает ввод/вывод (`cin`, `cout`).
2. `#include <cmath>` — подключает математические функции: `tan` (тангенс), `pow` (степень), `fabs` (модуль числа), `exp` (экспонента $e^x$).
3. `using namespace std;` — позволяет не писать `std::` перед стандартными именами.
4. `int main() {` — начало главной функции — точки старта программы.
5. `double a, b, c, y;` — объявление переменных вещественного типа: `a`, `b`, `c` — данные, `y` — результат.
6. `cout << "Vvedite a, b, c: ";` — выводит приглашение к вводу.
7. `cin >> a >> b >> c;` — считывает три числа с клавиатуры.
8. `y = tan(pow(a, 3) - fabs(b)) / (c * exp(b));` — вычисление формулы:
   - `pow(a, 3)` — это $a^3$;
   - `fabs(b)` — модуль (абсолютное значение) числа $b$, то есть $|b|$;
   - `pow(a, 3) - fabs(b)` — выражение $a^3 - |b|$;
   - `tan(...)` — тангенс этого выражения (аргумент в радианах);
   - `exp(b)` — вычисляет $e^{b}$;
   - `c * exp(b)` — знаменатель $c\,e^{b}$;
   - результат деления присваивается `y`.
9. `cout << "y = " << y << endl;` — вывод результата на экран.
10. `return 0;` — завершение программы без ошибок.
11. `}` — конец функции `main`.

## Пример работы (тест)
Ввод: `a=1  b=1  c=1`
Расчёт: `a^3-|b| = 1-1 = 0`, `tan(0) = 0`, поэтому числитель равен 0 — весь результат тоже 0.
Вывод: `y ≈ 0`
