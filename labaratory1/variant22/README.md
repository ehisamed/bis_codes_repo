# Вариант 22 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\mathrm{tg}^2 a - bc}{b\,\arccos(b^2+c^2)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = (pow(tan(a), 2) - b * c) / (b * acos(pow(b, 2) + pow(c, 2)));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `pow`, `tan`, `acos`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = (pow(tan(a), 2) - b * c) / (b * acos(pow(b, 2) + pow(c, 2)));` — вычисление:
   - `tan(a)` — тангенс $a$; `pow(tan(a), 2)` — квадрат $\mathrm{tg}^2 a$;
   - `b * c` — произведение $bc$; разность даёт числитель;
   - `pow(b,2)` и `pow(c,2)` — квадраты $b^2$ и $c^2$; их сумма — аргумент арккосинуса (должен быть в $[-1,1]$);
   - `acos(...)` — арккосинус этой суммы;
   - `b * acos(...)` — знаменатель;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=0.5  c=0`
Расчёт: `tan(1)≈1.557408`, в квадрате `≈2.425519`; `bc=0`; числитель `≈2.425519`. `b^2+c^2=0.25`, `arccos(0.25)≈1.318116`; знаменатель `=0.5*1.318116≈0.659058`.
Вывод: `y ≈ 3.680281`
