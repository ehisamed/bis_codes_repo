# Вариант 30 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\sin\sqrt{a+b}}{a\,\mathrm{tg}^2(b+c)}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = sin(sqrt(a + b)) / (a * pow(tan(b + c), 2));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `sin`, `sqrt`, `pow`, `tan`.
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — переменные для данных и результата.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = sin(sqrt(a + b)) / (a * pow(tan(b + c), 2));` — вычисление:
   - `a + b` — сумма (нужна ≥0); `sqrt(...)` — квадратный корень $\sqrt{a+b}$;
   - `sin(...)` — синус этого корня — числитель $\sin\sqrt{a+b}$;
   - `b + c` — сумма; `tan(...)` — тангенс суммы; `pow(..., 2)` — квадрат тангенса $\mathrm{tg}^2(b+c)$;
   - `a * pow(...)` — знаменатель;
   - деление даёт `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=1  b=0  c=1`
Расчёт: `sqrt(1+0)=1`, `sin(1)≈0.841471`; `tan(0+1)=tan(1)≈1.557408`, в квадрате `≈2.425519`; знаменатель `=1*2.425519≈2.425519`.
Вывод: `y ≈ 0.346924`
