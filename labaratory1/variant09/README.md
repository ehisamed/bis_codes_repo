# Вариант 9 — Лабораторная работа №1 (линейный алгоритм)

## Формула
$$y = \dfrac{\lg(|a|+3)^{c}}{b\cdot 10^{a}}$$

## Блок-схема
Файл `scheme.drawio`.

## Код (`solution.cpp`)
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cout << "Vvedite a, b, c: ";
    cin >> a >> b >> c;

    y = pow(log10(fabs(a) + 3), c) / (b * pow(10, a));

    cout << "y = " << y << endl;
    return 0;
}
```

## Объяснение построчно
1. `#include <iostream>` — ввод/вывод.
2. `#include <cmath>` — `log10` (десятичный логарифм), `fabs` (модуль), `pow` (степень).
3. `using namespace std;` — упрощает запись.
4. `int main() {` — начало главной функции.
5. `double a, b, c, y;` — объявление переменных.
6. `cout << "Vvedite a, b, c: ";` — приглашение к вводу.
7. `cin >> a >> b >> c;` — чтение чисел.
8. `y = pow(log10(fabs(a) + 3), c) / (b * pow(10, a));` — вычисление:
   - `fabs(a)` — модуль $|a|$; `fabs(a) + 3` — прибавляем 3;
   - `log10(...)` — десятичный логарифм $\lg(|a|+3)$;
   - `pow(..., c)` — возводит результат в степень $c$ — это числитель $\lg(|a|+3)^{c}$;
   - `pow(10, a)` — это $10^{a}$; `b * pow(10, a)` — знаменатель $b\cdot 10^{a}$;
   - результат деления присваивается `y`.
9. `cout << "y = " << y << endl;` — вывод результата.
10. `return 0;` — успешное завершение.
11. `}` — конец `main`.

## Пример работы (тест)
Ввод: `a=0  b=1  c=2`
Расчёт: `|a|+3=3`, `lg(3)≈0.477121`, в степени `c=2` → `≈0.227645`; `10^a=1`, `b*1=1`.
Вывод: `y ≈ 0.227645`
