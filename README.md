## ✨ О репозитории

Этот репозиторий создан для хранения лабораторных работ по программированию. Здесь собраны готовые примеры на **C++**, блок-схемы алгоритмов и пошаговые пояснения к решениям.

Материалы рассчитаны в первую очередь на начинающих: каждая задача сопровождается исходным кодом и объяснением того, как формула или алгоритм превращается в программу.

## 🧭 Что уже есть

### Лабораторная работа №1

Первая лабораторная посвящена линейным алгоритмам и вычислению математических выражений.

В работе доступны **30 вариантов**, и для каждого варианта подготовлены:

- 💻 `solution.cpp` — решение на C++;
- 🔷 `scheme.drawio` — блок-схема алгоритма;
- 📖 `README.md` — формула, разбор кода, пример работы и инструкция по запуску.

## 🗂️ Структура проекта

```text
.
├── README.md                 ← описание репозитория
├── GUIDE.md                  ← общий гайд по C++ и запуску программ
└── labaratory1/
    ├── variant01/
    │   ├── README.md         ← объяснение варианта
    │   ├── scheme.drawio     ← блок-схема
    │   └── solution.cpp      ← исходный код
    ├── variant02/
    ├── ...
    └── variant30/
```

## 🚀 Быстрый старт

1. Выберите нужный вариант в папке [`labaratory1`](labaratory1/).
2. Откройте его `README.md` и ознакомьтесь с формулой и объяснением.
3. Изучите или скопируйте код из `solution.cpp`.
4. Откройте `scheme.drawio` в [diagrams.net](https://app.diagrams.net/) или через расширение Draw.io для VS Code.
5. Соберите и запустите программу в любой среде с поддержкой C++.

Для знакомства с основами языка используйте [общий гайд по C++](GUIDE.md).

## 🔔 Как следить за обновлениями

Чтобы не пропустить новые лабораторные работы, объяснения, решения и другие изменения:

1. Откройте страницу этого репозитория на GitHub.
2. В верхней части страницы нажмите кнопку **Watch**.
3. Выберите **All Activity**, чтобы получать уведомления обо всех обновлениях репозитория.

После этого GitHub будет сообщать о новых изменениях и обсуждениях. Если кнопка уже называется **Watching**, значит, вы уже подписаны.

## 🛠️ Технологии и инструменты

- **C++** — основной язык программирования;
- **C++ Standard Library** — ввод, вывод и математические функции;
- **Visual Studio / VS Code** — разработка и запуск программ;
- **Draw.io** — создание и просмотр блок-схем;
- **GitHub** — хранение и развитие учебных материалов.

## 📚 Развитие репозитория

Репозиторий будет постепенно пополняться новыми лабораторными работами. Для каждой следующей работы сюда будут добавляться:

- 🧩 новые варианты заданий;
- 📝 объяснения того, как решить задачу;
- 🧠 разбор используемых алгоритмов и конструкций языка;
- 🔀 блок-схемы и другие визуальные материалы;
- ✅ примеры входных и выходных данных;
- 📦 все дополнительные файлы, необходимые для выполнения лабораторной.

Цель проекта — собрать материалы в одном месте, чтобы решение было не только готовым, но и понятным для самостоятельного изучения.
