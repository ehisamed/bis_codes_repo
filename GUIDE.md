## 1. Как устроена простейшая программа на C++

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a, b, c, y;
    cin >> a >> b >> c;
    y = a + b + c;
    cout << y << endl;
    return 0;
}
```

Разберём каждую часть по отдельности.

## 2. `#include` — подключение библиотек ("пакетов")

В C++ нет "пакетов" в том смысле, как в Python или Java. Вместо этого используются **заголовочные файлы** (header files) — это файлы с готовым кодом, который кто-то уже написал за вас (функции ввода-вывода, математику, работу со строками и т.д.). Чтобы воспользоваться этим кодом, его нужно **подключить** директивой `#include`.

```cpp
#include <iostream>   // ввод/вывод: cin, cout
#include <cmath>      // математика: sqrt, pow, sin, cos, log и т.д.
#include <string>     // работа со строками (std::string)
#include <cstdlib>    // разные утилиты (rand, exit и т.д.)
```

Синтаксис: `#include <имя_библиотеки>`. Треугольные скобки `< >` означают "искать в стандартных системных папках компилятора". Директива `#include` — это не оператор C++, а команда **препроцессору** (программе, которая обрабатывает текст перед компиляцией): она буквально вставляет содержимое указанного файла в начало вашего файла.

Если забыть подключить нужную библиотеку — компилятор выдаст ошибку вида `'sqrt' was not declared in this scope` ("функция sqrt не объявлена").

## 3. `using namespace std;`

Все стандартные средства C++ (`cin`, `cout`, `string` и т.п.) находятся в **пространстве имён** (namespace) `std` — это как "папка с именами", которая не даёт функциям и переменным из разных библиотек конфликтовать друг с другом.

Без этой строки пришлось бы писать полное имя каждый раз:

```cpp
std::cin >> a;
std::cout << a;
```

Строка `using namespace std;` говорит компилятору: "разреши использовать имена из `std` без приставки `std::`". Это удобно для учебных программ, хотя в больших проектах так делать не рекомендуется (может привести к конфликтам имён).

## 4. Функция `main` — точка входа

```cpp
int main() {
    // тело программы
    return 0;
}
```

- `int main()` — это специальная функция, с которой операционная система **начинает выполнение** программы. Без неё программа не соберётся.
- `int` перед `main` означает, что функция возвращает целое число — код завершения программы.
- Фигурные скобки `{ }` ограничивают **тело функции** — набор инструкций, которые выполняются одна за другой сверху вниз.
- `return 0;` в конце означает "программа завершилась успешно, без ошибок". Если бы вернули, например, `return 1;`, операционная система восприняла бы это как признак ошибки.

## 5. Переменные и типы данных

**Переменная** — это именованная область памяти, где хранится значение. Перед использованием переменную нужно **объявить**, указав её тип.

```cpp
double a, b, c, y;   // четыре переменные вещественного типа
int n;                // целое число
char ch;              // один символ
bool flag;            // логическое значение true/false
```

Основные типы, которые встречаются в лабораторных:

| Тип     | Что хранит                                  | Пример значения |
| ---------- | ---------------------------------------------------- | ----------------------------- |
| `int`    | целое число                                | `5`, `-12`                |
| `double` | вещественное (дробное) число | `3.14`, `-0.001`          |
| `char`   | один символ                                | `'a'`, `'5'`              |
| `bool`   | логическое значение                | `true`, `false`           |

Мы почти везде используем `double`, потому что в формулах участвуют дробные числа и результаты математических функций (корень, логарифм, синус и т.д.) — они всегда вещественные.

**Присваивание** — операция `=` кладёт значение справа в переменную слева:

```cpp
y = 2 * a + 1;   // сначала вычисляется правая часть, потом результат кладётся в y
```

## 6. Ввод и вывод данных: `cin` и `cout`

- `cin` (от *console input*) — читает данные, которые пользователь вводит с клавиатуры.
- `cout` (от *console output*) — выводит данные на экран.
- `>>` — оператор извлечения (используется с `cin`): "взять число из потока ввода и положить в переменную".
- `<<` — оператор вставки (используется с `cout`): "взять значение и отправить в поток вывода".
- `endl` — переводит строку на экране (аналог "нажать Enter").

```cpp
cout << "Vvedite a, b, c: ";   // печатаем подсказку
cin >> a >> b >> c;             // считываем 3 числа подряд
cout << "y = " << y << endl;    // печатаем текст, затем значение переменной, затем перевод строки
```

При вводе нескольких чисел подряд их можно разделять пробелом или переводом строки — `cin` сам пропускает пробельные символы между числами.

## 7. Математические функции (`<cmath>`)

Все формулы из лабораторной работы используют функции из библиотеки `<cmath>`. Аргументы тригонометрических функций указываются **в радианах**, а не в градусах.

| Функция C++                    | Математическое обозначение | Что делает                                                                                           |
| ------------------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `pow(x, y)`                         | $x^{y}$                                           | возводит`x` в степень `y`                                                                 |
| `sqrt(x)`                           | $\sqrt{x}$                                        | квадратный корень из`x` (x должен быть ≥ 0)                                    |
| `fabs(x)`                           | $\lvert x\rvert$                                  | модуль (абсолютное значение) вещественного числа                    |
| `abs(x)`                            | $\lvert x\rvert$                                  | модуль целого числа (для`int`)                                                          |
| `exp(x)`                            | $e^{x}$                                           | экспонента (число e в степени x)                                                       |
| `log(x)`                            | $\ln x$                                           | натуральный логарифм (x > 0)                                                               |
| `log10(x)`                          | $\lg x$                                           | десятичный логарифм (x > 0)                                                                 |
| `sin(x)`, `cos(x)`, `tan(x)`    | $\sin x, \cos x, \mathrm{tg}\,x$                  | тригонометрические функции (x в радианах)                                   |
| `asin(x)`, `acos(x)`, `atan(x)` | $\arcsin x, \arccos x, \mathrm{arctg}\,x$         | обратные тригонометрические функции (результат в радианах) |

### Про `pow` подробнее

`pow(x, y)` — универсальная функция возведения в степень: и для целых, и для дробных показателей.

```cpp
pow(2, 3);     // 2^3 = 8
pow(a, 2);     // a^2 (квадрат числа a)
pow(x, 0.5);   // то же самое, что sqrt(x) — корень
```

Важно: `pow` возвращает `double`, даже если аргументы — целые числа.

### Про `sqrt` подробнее

`sqrt(x)` — квадратный корень. Если передать отрицательное число, результат будет `nan` ("not a number", ошибка вычисления) — поэтому в формулах перед корнем часто стоит `fabs(...)`, чтобы гарантировать неотрицательное подкоренное выражение.

### Пример использования нескольких функций вместе

Формула $y = \dfrac{\sqrt{|a|^{b}-2}}{b(c^3-1)}$ на C++ пишется так:

```cpp
y = sqrt(pow(fabs(a), b) - 2) / (b * (pow(c, 3) - 1));
```

Читаем изнутри наружу:

1. `fabs(a)` — модуль `a`;
2. `pow(fabs(a), b)` — возводим модуль `a` в степень `b`;
3. вычитаем `2`;
4. `sqrt(...)` — берём корень из результата;
5. `pow(c, 3)` — куб `c`, минус `1` — это знаменатель в скобке;
6. умножаем на `b`;
7. делим числитель на знаменатель.

## 8. Операторы и приоритет действий

| Оператор | Значение                                                               |
| ---------------- | ------------------------------------------------------------------------------ |
| `+`            | сложение                                                               |
| `-`            | вычитание                                                             |
| `*`            | умножение                                                             |
| `/`            | деление                                                                 |
| `%`            | остаток от деления (только для целых чисел) |

Приоритет как в обычной математике: сначала умножение/деление, потом сложение/вычитание. Круглые скобки `()` меняют порядок вычислений — то, что внутри скобок, считается первым.

```cpp
y = 2 * a + b;      // сначала 2*a, потом +b
y = 2 * (a + b);     // сначала a+b, потом умножение на 2 — совсем другой результат!
```

## 10. Типичные ошибки новичков

1. **Забыли `;` в конце строки.** Каждая инструкция в C++ заканчивается точкой с запятой.
2. **Забыли подключить `<cmath>`,** но используют `sqrt`/`pow`/`sin` — ошибка компиляции "not declared".
3. **Деление на 0** — для `double` даёт `inf` (бесконечность), программа не упадёт, но результат бессмысленный.
4. **Корень из отрицательного числа** (`sqrt` от `x < 0`) — результат `nan`. Проверяйте формулу на допустимые входные данные (это и делает `fabs` в некоторых вариантах).
5. **Использование `int` вместо `double`** там, где нужны дробные значения — при делении `int` на `int` дробная часть отбрасывается (целочисленное деление).
6. **Путаница градусов и радианов** — все тригонометрические функции C++ работают с радианами, а не градусами. Чтобы перевести градусы в радианы: `радианы = градусы * M_PI / 180`.

## 11. Как запустить программу в Visual Studio

1. Открыть Visual Studio → **Создать проект** → выбрать шаблон **"Пустой проект"** (Empty Project) или **"Консольное приложение"** (Console App) для C++.
2. В обозревателе решений (Solution Explorer) щёлкнуть правой кнопкой на "Исходные файлы" (Source Files) → **Добавить → Создать элемент** → выбрать `.cpp` файл (например, `main.cpp`).
3. Скопировать код из `solution.cpp` нужного варианта и вставить в созданный файл.
4. Собрать проект: **Ctrl+Shift+B** (Build).
5. Запустить без отладки: **Ctrl+F5** — откроется консольное окно, куда нужно ввести числа `a`, `b`, `c` через пробел и нажать Enter.
